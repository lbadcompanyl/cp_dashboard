# บันทึกการประมวลผลข้อมูล (Record of Processing Activities — ย่อ)

> เอกสารนี้เป็น **บันทึกภายใน** เพื่อแสดงความรับผิดชอบตาม PDPA (พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล)
> ไม่ใช่คำแนะนำทางกฎหมาย — หากใช้เชิงพาณิชย์หรือสเกลใหญ่ ควรปรึกษาที่ปรึกษากฎหมาย/DPO

## 1. วัตถุประสงค์การประมวลผล
วิเคราะห์ความคิดเห็น (sentiment) ของคอมเมนต์บนโพสสาธารณะ **เป็นภาพรวม** เพื่อ insight ภายในองค์กร
(เช่น กระแสตอบรับแคมเปญ, ประเด็นที่ถูกพูดถึง) — ไม่ใช่เพื่อระบุ ติดตาม หรือทำโปรไฟล์รายบุคคล

## 2. แหล่งข้อมูล
คอมเมนต์สาธารณะจาก YouTube / Facebook / TikTok ผ่าน:
- **YouTube Data API v3** (ช่องทางทางการของ Google)
- **ScrapeCreators API** (ผู้ให้บริการภายนอกสำหรับ FB/TikTok)

## 3. ฐานทางกฎหมาย
**ประโยชน์โดยชอบด้วยกฎหมาย (legitimate interest)** — วิเคราะห์ความเห็นสาธารณะแบบภาพรวม
โดยไม่กระทบสิทธิเสรีภาพของเจ้าของข้อมูลเกินสมควร (ไม่เก็บ/ไม่เผยแพร่ข้อมูลระบุตัวตน)

## 4. ประเภทข้อมูลและการเก็บรักษา
| ข้อมูล | จัดเก็บถาวรหรือไม่ |
|---|---|
| ข้อความคอมเมนต์ (raw) | ❌ **ไม่เก็บ** — ประมวลผลในหน่วยความจำแล้วทิ้ง |
| ชื่อ/บัญชีผู้คอมเมนต์ | ❌ **ไม่เก็บ** — ตัดออกก่อนแสดงผล (โหมด anonymize เป็นค่าเริ่มต้น) |
| ผลสรุป aggregate (%, จำนวน, คำที่พูดถึง) | ✅ เก็บได้ — ระบุตัวบุคคลไม่ได้ |
| ตัวอย่างคอมเมนต์ | เป็นข้อความ **ถอดความ** (paraphrase) ไม่ใช่ต้นฉบับ และไม่มีชื่อ |

## 5. มาตรการทางเทคนิค
- Backend (Cloudflare Worker) **ไม่มีฐานข้อมูล ไม่ persist** — ทำงานแบบ request/response แล้วจบ
- ผลลัพธ์ที่ส่งกลับหน้าเว็บเป็น **aggregate** เท่านั้น (ค่าเริ่มต้นไม่มีชื่อรายคน)
- **PDF / JPEG** = รายงานภาพรวม (aggregate) ไม่มีข้อความ/ชื่อรายคน
- **Excel / CSV** = ชีตสรุป (aggregate) **+ ชีต "รายคอมเมนต์"** (ข้อความ + ผล sentiment
  โดย**ไม่มีชื่อผู้คอมเมนต์**) สำหรับตรวจความถูกต้อง (QA) / แชร์ภายในทีม
- **มุมมอง audit (บนจอ)**: แสดงข้อความ + ผลที่ตีได้ เพื่อตรวจความถูกต้อง — ตัดชื่อออกแล้ว
- **การจับสัญญาณ IO**: ใช้ชื่อผู้คอมเมนต์ (นับว่าคนเดียวโพสต์กี่ครั้ง) **ในหน่วยความจำของ worker
  ระหว่างประมวลผลเท่านั้น** ไม่ส่งชื่อกลับหน้าเว็บ ไม่บันทึก — ผลลัพธ์คืนเฉพาะ **ธง + เหตุผล**
  · เป็น **สัญญาณน่าสงสัย ไม่ใช่ข้อสรุปว่าใครเป็น IO** และไม่ระบุตัวบุคคล
  · 🚫 ห้ามนำผลนี้ไปกล่าวหา/ระบุตัวผู้ใช้รายบุคคล — ใช้ดูภาพรวมว่ากระแสอาจถูกปั่นหรือไม่เท่านั้น
- ทุกกรณี Backend **ไม่จัดเก็บ (persist)** ข้อมูล; ไฟล์ที่ได้ให้ถือเป็นข้อมูลภายใน
  ใช้ตามหลัก aggregate/QA ไม่นำข้อความไปเผยแพร่ต่อแบบระบุตัวตน

## 6. ขอบเขตการใช้งาน
- ✅ ใช้ **ภายในองค์กร** เพื่อวิเคราะห์ภาพรวม
- 🚫 ไม่นำไปเผยแพร่ข้อความ/ชื่อผู้คอมเมนต์แบบระบุตัวตน
- 🚫 ไม่ใช้ทำ direct marketing รายบุคคล หรือทำโปรไฟล์บุคคล

## 7. ข้อควรระวัง (ToS ของแพลตฟอร์ม)
- **YouTube**: ใช้ API ทางการ — สอดคล้อง ToS
- **Facebook / TikTok**: การดึงคอมเมนต์ผ่าน scraper ขัดกับ ToS ของแพลตฟอร์ม
  (ความเสี่ยงเชิงสัญญาอยู่ที่ผู้ให้บริการ scraper) — ใช้อย่างรับผิดชอบและเท่าที่จำเป็น
