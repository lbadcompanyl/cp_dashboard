# เกณฑ์ตัดสิน Sentiment "ต่อ CP" (rubric)

> เอกสารนี้คือ **หัวใจของความแม่นยำ** — ทั้งคนที่ label และ AI ใช้เกณฑ์ชุดเดียวกันนี้
> ถ้าเกณฑ์ไม่ชัด ข้อมูลจะขัดกันเอง แล้วไม่ว่าจะใช้วิธีไหนก็พังหมด
>
> **ฉบับร่าง — รอเจ้าของตรวจ/แก้** (ส่วนที่ยังไม่แน่ใจทำเครื่องหมาย ❓ ไว้)

## 1. เป้าหมาย: วัด "ท่าทีต่อเครือ CP" เท่านั้น

⚠️ **ไม่ใช่อารมณ์รวมของคอมเมนต์** — ให้ดูเฉพาะว่าคนเขียน **รู้สึกยังไงกับ CP**

| คอมเมนต์ | อารมณ์รวม | **ต่อ CP (ที่เราต้องการ)** |
|---|---|---|
| "รัฐห่วยมาก แต่ CP ช่วยแก้ปัญหาได้ดี" | ปนๆ | ✅ **บวก** |
| "ปลานี่ระบาดน่ากลัวมาก ต้องเร่งกำจัด" | ลบมาก | ✅ **ไม่เกี่ยว** (ไม่ได้พูดถึง CP) |
| "สงสารชาวบ้าน เดือดร้อนกันหมด" | ลบ | ✅ **ไม่เกี่ยว** |

## 2. ป้าย 4 แบบ

| ป้าย | ความหมาย | ตัวอย่าง |
|---|---|---|
| **`positive`** บวกต่อ CP | ชื่นชม · สนับสนุน · ปกป้อง · เห็นใจ · ขอบคุณ (จริงใจ) | "CP ช่วยเหลือเร็วดี ชื่นชม" · "ไม่ใช่ความผิดเขาซะหน่อย" |
| **`neutral`** กลางต่อ CP | เอ่ยถึงแบบข้อเท็จจริง ไม่แสดงท่าที · ถาม · ขอข้อมูลเพิ่ม | "CP ออกแถลงการณ์แล้วนะ" · "CP เกี่ยวข้องยังไงเหรอ" |
| **`negative`** ลบต่อ CP | ตำหนิ · กล่าวหา · ประชด · เรียกร้องให้รับผิดชอบ · สาปแช่ง · เรียกร้องให้แบน | "CP ต้องรับผิดชอบ" · "ทำลายระบบนิเวศแล้วเงียบ" · "แบนสินค้าเลย" |
| **`not_related`** ไม่เกี่ยวกับ CP | ไม่ได้พูดถึงเครือเลย (พูดถึงปลา/รัฐ/ชาวบ้าน/เรื่องอื่น) | "ปลามันดุมาก" · "รัฐต้องเร่งแก้" · "สู้ๆ นะครับ" |

> 📌 **`not_related` สำคัญมาก** — คอมเมนต์ปลาหมอคางดำส่วนใหญ่ **ไม่ได้พูดถึง CP เลย**
> ถ้าเหมารวมเป็น "ลบ" เปอร์เซ็นต์จะเพี้ยนทันที (ดูเหมือนคนด่า CP ทั้งที่เขาด่าปลา)

## 3. ลำดับการตัดสิน (ทำตามนี้ทีละข้อ)

```
1. คอมเมนต์นี้พูดถึง CP หรือเครือหรือไม่?  (ดูข้อ 4)
   └─ ไม่ → not_related  ⛔ จบ
2. เป็นชื่อลวงที่ไม่ใช่เครือหรือไม่? (ดูข้อ 4)
   └─ ใช่ → not_related  ⛔ จบ
3. ท่าทีต่อ CP เป็นยังไง?
   ├─ ตำหนิ/กล่าวหา/ประชด        → negative
   ├─ ชื่นชม/ปกป้อง/สนับสนุน      → positive
   └─ เอ่ยถึงเฉยๆ / ถาม / ไม่ชัด  → neutral
```

## 4. อะไรนับว่า "CP" / อะไรไม่นับ

**✅ นับเป็น CP** (ตรงกับ `CP_BRANDS` ใน `functions/api/_lib/noise.js`):
ซีพี · CP · เจริญโภคภัณฑ์ · Charoen Pokphand · **เจียรวนนท์** (ชื่อผู้บริหาร) ·
ซีพีเอฟ/CPF · ซีพี ออลล์ · ซีพีแรม · ซีพี แอ็กซ์ตร้า · **เซเว่น/7-11 · แม็คโคร · โลตัส · ทรู**

> 💡 พูดถึง **บริษัทในเครือ** = นับเป็น CP (เช่น "ไม่ซื้อของเซเว่นแล้ว" ในบริบทข่าว CP = ลบต่อ CP)

**❌ ไม่นับ — ชื่อลวง** (ตรงกับ `CP_FALSE`):
บีแอลซีพี/BLCP (โรงไฟฟ้า) · ซีพีเอ็น/CPN (Central Pattana) · บีซีพีจี/บีซีพี (บางจาก) ·
ทรูดิจิทัล พาร์ค (สถานที่) · ทรูธโซเชียล/Truth Social (แอปทรัมป์) · ซีพีพี = ศัพท์การแพทย์

**✅ นับด้วย — กล่าวหาโดยไม่เอ่ยชื่อ** (เมื่อบริบทชัดว่าหมายถึง CP):
"บริษัทยักษ์ใหญ่ที่นำเข้ามา" · "เจ้าสัว" · "นายทุนใหญ่" ในกระทู้ปลาหมอคางดำ → **negative**
❓ *ข้อนี้เจ้าของยืนยันด้วย — ตีความกว้างไปจะจับผิด แต่ตีความแคบจะพลาดคอมเมนต์ที่ด่าจริง*

## 6. กฎเสริม

- **ประชดสำคัญที่สุด** — ในกระแสวิกฤต คอมเมนต์เชิงประชดเยอะมาก ให้ดู **เจตนา** ไม่ใช่คำ
  สัญญาณ: ขอบคุณเกินจริง · 🙏😂 ต่อท้ายประโยคด่า · "เก่งมากครับ" ในบริบทลบ
- **ไม่แน่ใจ = `neutral`** ไม่ใช่เดาเป็น negative (ตีเป็นลบเกินจริงคือความผิดพลาดที่แพงที่สุด)
- **ยาวไม่เกี่ยว** — คอมเมนต์สั้นๆ "ซวยละ" ที่ไม่มี CP = `not_related`
- **label ตามที่เขียน ไม่ใช่ตามที่เรารู้** — ห้ามเติมบริบทที่คอมเมนต์ไม่ได้พูด

## 7. วิธี label (ใช้เครื่องมือที่มีอยู่แล้ว)

1. วิเคราะห์โพสปลาหมอคางดำในแท็บ **💬 กระแสความเห็น**
2. เปิด **🔍 ตรวจ sentiment รายคอมเมนต์** → **📊 Excel**
3. ในไฟล์ Excel แก้คอลัมน์ **`ผล sentiment`** ให้ถูกตามเกณฑ์นี้ (ใส่: `positive` / `neutral` / `negative` / `not_related`)
4. เพิ่มคอลัมน์ **`หมายเหตุ`** เมื่อเป็นเคสยาก (จะได้เอาไปเป็นตัวอย่างสอน AI)
5. เป้าหมาย: **~300 คอมเมนต์** — แบ่ง **200 สอน AI** + **100 ไว้วัดผล** (ห้ามปนกัน)

> ⚠️ **test set ห้ามเอาไปสอน** — ไม่งั้นวัดผลจะหลอกตัวเอง (เหมือนให้ข้อสอบพร้อมเฉลย)

## 8. ❓ ที่รอเจ้าของเคาะ

1. **เคส #4** "ควรตรวจสอบว่า CP เกี่ยวไหม" → `negative` หรือ `neutral`?
2. **เคส #8** "ไก่ CP อร่อย" (ชมสินค้า) → `positive` หรือ `neutral`?
3. **กล่าวหาโดยไม่เอ่ยชื่อ** ("เจ้าสัว" / "นายทุนใหญ่") → นับเป็น CP ไหม?
4. อยากแยก **"ลบรุนแรง"** (เรียกร้องแบน/ฟ้อง) ออกจาก "ลบทั่วไป" ไหม?
