## 2. 🧠 ระบบเรียนรู้ — หัวใจของสิ่งที่เจ้าของสั่ง

เจ้าของสั่ง 2 ประโยคนี้ในวันเดียวกัน:

> **"ต้องให้ tool ตัวนี้ learning ได้ด้วย"**
> **"ต้องให้จำ pattern ที่ social มันจะผิดด้วย"**

ระบบที่มีอยู่ทำงาน 3 ชั้น — **แยก "แก้รายงาน" ออกจาก "สอนระบบ" โดยตั้งใจ**

```
① ผู้ใช้กดแก้ป้ายบนหน้าเว็บ   → แก้รายงานใบนั้นทันที · ไม่ยิงหลังบ้าน
② กดปุ่มส่งเข้ากองรอตรวจ      → POST /feedback → KV · ⚠️ ยังไม่มีผลกับใคร
③ เอากองมาวัดกับชุดเฉลย 475 ใบ → ผ่านเกณฑ์ 6 ข้อ แล้ว "คน" เขียนเป็นกฎในโค้ด
```

**สำหรับงาน Zocial โดยเฉพาะ** — `POST /feedback` มี 2 ช่องที่เพิ่มให้ (worker v34)

| ช่อง | เก็บอะไร | ทำไมสำคัญ |
|---|---|---|
| `from` | ป้ายเดิมที่ **Zocial** ตี | ไม่มี = รู้แค่ว่าผิด แต่ไม่รู้ว่า**ต้นทางผิดแบบไหน** |
| `src` | แก้มาจากชั้นไหน (`zocial` / `ai`) | แยกได้ว่า Zocial ผิด หรือ AI ผิด |

pattern ที่สะสมจาก 2 ช่องนี้ = ข้อมูลที่บอกว่า **ครั้งหน้าต้องส่งใบไหนให้ AI ตรวจ**
= ประหยัดเงินโดยตรง (ไม่ต้องตรวจทุกใบ)

> 🚫 **ห้ามให้ของในกองไปสอน AI อัตโนมัติ** — เจ้าของสั่งไว้ชัด
> ถ้าสอนเอง ความแม่นจะเปลี่ยนทุกวันโดยไม่มีใครวัดสักครั้ง แล้ววันหนึ่งจะพบว่าแย่ลง
> มานานแล้วโดยไม่รู้ว่าตั้งแต่เมื่อไหร่ · และ `POST /feedback` เปิดโดยไม่มีกุญแจได้
> **ก็เพราะของในกองไม่มีผลกับใคร** — ถ้าวันไหนให้มันมีผลโดยตรง ต้องปิดด้วยกุญแจทันที

## 3. 📏 บทเรียนที่ห้องนี้เจ็บมาแล้ว — อย่าเจ็บซ้ำ

### 🔴 "ไม่รู้ ≠ ค่าใดค่าหนึ่ง" — เจอ 3 รอบใน session เดียว

| เกิดอะไร | อาการที่ผู้ใช้เห็น |
|---|---|
| AI ตอบไม่ได้ → โค้ดเติม "กลาง" ให้เงียบๆ | รายงานว่าโมเดลได้ 10.8% ทั้งที่ไม่เคยได้คำตอบจากโมเดลเลยสักข้อ |
| แกะ JSON ไม่ได้ → คืน `{summary:"", keywords:[], samples:[]}` | "กดสรุปใหม่แล้วคำกับตัวอย่างหายหมด สรุปเหมือนเดิมเป๊ะ" |
| ต้นทางไม่ส่ง `Sentiment` → นับเป็น Neutral | Zocial ตีข้อความว่าง 285 ใบเป็นกลาง → % เพี้ยนไป 4-8 จุด |

**กฎ:** ตอบไม่ได้ต้อง**โยน error หรือติดธง** ห้ามกลืนแล้วคืนค่าที่ดูเหมือนคำตอบ
· และ**ก่อนเชื่อตัวเลขไหน ให้ดูการกระจายก่อน** ถ้ากองอยู่ค่าเดียวผิดธรรมชาติ = สงสัยไว้ก่อน

### 🔴 ป้ายบนหน้าจอโกหกได้ ทั้งที่ตัวเลขถูก

หน้า sentiment เคยขึ้น **"พูดถึงเครือ CP 48 · ไม่เกี่ยวกับ CP 0"** ทั้งที่มีคอมเมนต์เอ่ยถึง CP จริงๆ
แค่ 1-2 ใบ · สาเหตุ: หมวด `not_related` ถูกยกเลิกไปแล้ว แต่ป้ายค้างมาจากตอนที่ยังแยก

**กฎ:** เปลี่ยนนิยามเมื่อไหร่ **ต้องไล่แก้ป้ายทุกที่ที่อ้างถึงนิยามนั้น** (หน้าจอ · CSV · tooltip)

### 🔴 เทสต์ที่ผ่านตลอดไม่มีค่า — ต้องพิสูจน์ว่าจับของพังได้

ใน session นี้เขียนเทสต์แล้ว**จับไม่ได้ 2 ครั้ง** ทั้งที่ดูเหมือนเขียนถูก
- เทสต์ "ยิงไม่สำเร็จห้ามลบของเดิม" เช็คแต่สรุป → ตัวอย่างหายเกลี้ยงแต่เทสต์ผ่าน
- เทสต์ "ต้องเอาใบในกลุ่มเดียวกันมาแทน" → ข้อมูลทดสอบบังเอิญให้ผลเหมือนกันทั้ง 2 ทาง

**กฎ:** เขียนเทสต์เสร็จ **ต้องลองทำให้พังแล้วดูว่าตกจริง** ก่อนเชื่อว่ามันคุมอะไรได้

### 🔴 `functions/` พังไฟล์เดียว = ทั้งเว็บ deploy ไม่ได้

จุลภาคเกิน 1 ตัวทำให้ทุก push ของ**ทุกห้อง**ไม่ขึ้นเว็บ 3 วันโดยไม่มีอะไรแจ้ง
· `node --check` **จับไม่ได้** · ต้องรัน `node tests/imports.mjs` ก่อน push ทุกครั้งที่แตะ `functions/`

### 🔴 ตัวเลขต้องมาจากผลรันจริง

เคยประเมินว่า sonnet ถูกกว่า 60% · วัดจริงได้ 27% เพราะมันเขียนคำตอบยาวกว่า
**อย่าคิดต้นทุนจากราคาต่อโทเคนอย่างเดียว** — ต้องวัดจำนวนโทเคนที่ใช้จริงด้วย
