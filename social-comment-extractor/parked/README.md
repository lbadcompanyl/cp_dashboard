โฟลเดอร์นี้เก็บฟีเจอร์ที่ **ทำเสร็จแล้วแต่เจ้าของสั่งพักไว้ก่อน** ไว้หยิบกลับมาใช้ใน phase ถัดไป

## 📦 `io-detection.patch` — จับสัญญาณ IO (คอมเมนต์จัดตั้ง)

**สถานะ:** ทำเสร็จ + ทดสอบผ่านแล้ว · เจ้าของสั่งพักไว้ (24 ส.ค. 2026) — *"เอาไว้ก่อน ไว้ทำ phase หน้า"*

**ทำอะไรได้:**
- จับสัญญาณคอมเมนต์จัดตั้ง 4 แบบ (ข้อความยาวซ้ำ · คนเดียวคอมเมนต์หลายครั้ง · ช่วงเวลาถี่ผิดปกติ · ข้อความสั้นซ้ำ)
- บอกเป็น **% ของคอมเมนต์ทั้งหมด** + ปุ่ม **ตัดออกจากผลวิเคราะห์** (คำนวณใหม่ในเครื่อง ไม่เรียก API ซ้ำ)
- audit มีป้าย 🕵️ + เหตุผลรายใบ · export Excel/CSV เพิ่ม 2 คอลัมน์
- ใช้กฎตายตัว ไม่เรียก AI (อธิบายได้ · ผลนิ่ง · ไม่มีค่าโทเคนเพิ่ม)
- 🔒 ใช้ชื่อผู้คอมเมนต์ในหน่วยความจำ worker เท่านั้น **ไม่ส่งชื่อกลับหน้าเว็บ**

**ทดสอบไว้แล้ว:** unit test 5 เคส (รวมเคสเลี่ยงด้วยตัวซ้ำ/อิโมจิ) + Playwright end-to-end

## วิธีเอากลับมาใช้

```bash
git checkout dev && git pull origin dev
git am social-comment-extractor/parked/io-detection.patch
# ถ้าไฟล์ขยับไปมากจน apply ไม่ผ่าน:
git apply --3way social-comment-extractor/parked/io-detection.patch
```

หรือหยิบจาก branch ที่เก็บไว้: **`origin/claude/io-detection`** (commit `45210bb`)

> 🚫 **ห้ามใช้ `git merge claude/io-detection`** — เคยถอดโค้ดนี้ออกจาก dev ไปแล้ว
> git จะมองว่า "dev ตัดสินใจเรื่องนี้ไปแล้ว" แล้ว**กลืนของใหม่หายเงียบๆ**
> (กับดักเดียวกับที่ CLAUDE.md หัวข้อ 📦 เตือนไว้)
> ✅ ใช้ **`git am` จาก patch** หรือ **`git cherry-pick 45210bb`** เท่านั้น — ทั้งสองวิธีสร้าง commit ใหม่ ไม่ติดกับดัก

## ที่ต้องทำเพิ่มตอนเอากลับมา
