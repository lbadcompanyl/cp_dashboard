# ชุดข้อมูล label — สมบัติระยะยาวของโปรเจกต์

> 📌 **นี่คือของที่มีค่าที่สุด** — โมเดลเปลี่ยนได้ทุกปี แต่ชุดข้อมูลที่ label ถูกต้องใช้ได้ตลอด
> (ใช้สอน AI · ใช้วัดความแม่น · ใช้ fine-tune ในอนาคตถ้าปริมาณงานโตพอ)

## วิธีสร้าง (ใช้เครื่องมือที่มีอยู่แล้ว ไม่ต้อง label จากศูนย์)

1. เปิดแท็บ **💬 กระแสความเห็น** → เลือก **วัดท่าทีต่อ = 🏢 เครือ CP**
2. วิเคราะห์โพสปลาหมอคางดำ (หรือโพสอื่นที่มีคนพูดถึง CP)
3. เปิด **🔍 ตรวจ sentiment รายคอมเมนต์** → กด **📊 Excel**
4. ในไฟล์ Excel ไปที่ชีต **`รายคอมเมนต์`** — AI ตีมาให้แล้ว **คุณแค่แก้ที่ผิด**
5. เซฟไฟล์ไว้ในโฟลเดอร์นี้ ตั้งชื่อตามข้อ "การตั้งชื่อไฟล์"

> 💡 **AI ตีมาให้ก่อนแล้ว = เร็วกว่า label เองมาก** ส่วนใหญ่จะถูกอยู่แล้ว แก้เฉพาะที่ผิด

## รูปแบบไฟล์

| คอลัมน์ | ค่าที่ใส่ | จำเป็น |
|---|---|---|
| `ผล sentiment` | `บวก` / `กลาง` / `ลบ` / `ไม่เกี่ยวกับ CP` | ✅ |
| `ข้อความ` | ข้อความคอมเมนต์ (มาจากระบบแล้ว ไม่ต้องแก้) | ✅ |
| `หมายเหตุ` | *(เพิ่มเอง)* เขียนเมื่อเป็นเคสยาก เช่น "ประชด", "ชื่อลวง" | แนะนำ |

**เกณฑ์ตัดสินอยู่ที่ [`../RUBRIC-CP.md`](../RUBRIC-CP.md)** — เปิดอ่านก่อน label ทุกครั้ง

## การตั้งชื่อไฟล์

```
train-<หัวข้อ>-<วันที่>.xlsx     ← เอาไปสอน AI
test-<หัวข้อ>-<วันที่>.xlsx      ← เอาไว้วัดผลเท่านั้น
```
ตัวอย่าง: `train-blackchin-2026-08-20.xlsx` · `test-blackchin-2026-08-20.xlsx`

> ⚠️ **ห้ามเอาไฟล์ `test-` ไปสอน AI เด็ดขาด** — เหมือนให้ข้อสอบพร้อมเฉลย
> วัดผลจะสวยหลอกๆ แล้วเราจะไม่รู้เลยว่าจริงๆ แม่นแค่ไหน

## เป้าหมายจำนวน

| | จำนวน | ใช้ทำอะไร |
|---|---|---|
| **train** | ~200 | คัดเคสยากไปใส่ `CP_EXAMPLES` ใน `worker.js` |
| **test** | ~100 | วัดว่า AI แม่นกี่ % — วัดซ้ำได้ทุกครั้งที่แก้ prompt |

**ไม่ต้องได้ครบในวันเดียว** — label ไปเรื่อยๆ ระหว่างใช้งานจริงก็ได้

## เอาไปสอน AI ยังไง

เปิด `../worker/worker.js` → หาส่วน **`CP_EXAMPLES`** (อยู่บนสุดของไฟล์ มีคอมเมนต์กำกับ)
แล้วเพิ่มบรรทัดแบบนี้:

```js
{ t: "ข้อความคอมเมนต์", a: "negative" },   // เหตุผลสั้นๆ เช่น ประชด
```

**คัดเฉพาะเคสที่ AI เคยตอบผิด** (เคสง่ายที่ตอบถูกอยู่แล้วไม่ต้องใส่ — เปลืองโทเคนเปล่าๆ)
· ควรคละให้ครบทั้ง 4 ป้าย · ไม่ควรเกิน ~40 อัน
