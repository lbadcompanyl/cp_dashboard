## หลักคิดที่สำคัญที่สุด: **"แก้รายงาน" กับ "สอนระบบ" ต้องแยกกัน**

รวมเป็นอันเดียวเมื่อไหร่ = แก้ป้าย 1 ใบแล้วระบบเปลี่ยนวิธีคิดทันที
โดยไม่มีใครรู้ว่าไปทำให้ใบอื่นผิดเพิ่มกี่ใบ

| | แก้รายงาน | สอนระบบ |
|---|---|---|
| เห็นผลเมื่อไหร่ | **ทันที** | รอบถัดไป หลังผ่านการวัด |
| กระทบใคร | รายงานใบนั้นใบเดียว | **ทุกโพสที่วิเคราะห์ต่อจากนี้** |
| ต้องวัดก่อนไหม | ไม่ต้อง เจ้าของคือคนตัดสิน | **ต้อง** ไม่งั้นแย่ลงโดยไม่มีใครรู้ |

## 3 ชั้น

```
① กดแก้ป้ายบนหน้าเว็บ  (issue/sentiment.html)
      ↓  แก้รายงานใบนั้นทันที — ไม่ยิงหลังบ้านเลย
② กดปุ่ม "📥 ส่งเข้ากองรอตรวจ"  (POST /feedback → KV)
      ↓  ⚠️ เก็บไว้เฉยๆ ยังไม่มีผลกับใครทั้งสิ้น
③ เอากองมาวัดกับชุดสอบ 475 ใบ  (issue/sentiment-eval.html)
         ผ่านเกณฑ์ → เขียนเป็นกฎ/ตัวอย่างในโค้ด (คนทำ ไม่ใช่เครื่อง)
```

> 🚫 **ห้ามให้ของในกองไปสอน AI อัตโนมัติเด็ดขาด** (เจ้าของสั่งไว้ชัด)
> ถ้าสอนเอง **ความแม่นจะเปลี่ยนทุกวันโดยไม่มีใครวัดสักครั้ง** แล้ววันหนึ่งจะพบว่า
> แย่ลงมานานแล้วโดยไม่รู้ว่าตั้งแต่เมื่อไหร่ — ขัดกฎ "ตัวเลขต้องมาจากผลรันจริง"
>
> 🛡 **นี่คือตัวกันคนยิงขยะเข้ามาสอนระบบด้วย** — `POST /feedback` เปิดไว้ได้โดยไม่ต้องมีกุญแจ
> เพราะ**ของในกองไม่มีผลกับใคร** ต่อให้มีคนยิงขยะเข้ามาก็ได้แค่กองขยะที่คนเห็นแล้วลบทิ้ง
> · ถ้าวันไหนเปลี่ยนให้ของในกองมีผลโดยตรง **ต้องปิดช่องนี้ด้วยกุญแจทันที**

## 🔒 กฎฝั่งเทคนิค

| กฎ | เพราะอะไร |
|---|---|
| **blob เดียว อ่าน 1 เขียน 1 ต่อคำขอ** ห้ามแตกเป็น key รายใบ | KV ของแผนฟรีเขียนได้ 1,000 ครั้ง/วัน **ใช้ร่วมกันทั้งโปรเจกต์** |
| ไม่มีของใหม่ = **ไม่เขียน KV เลย** | กดปุ่มซ้ำไม่ควรกินโควตา |
| ส่งซ้ำข้อความเดิม = ข้าม | ไม่งั้นกองบวมด้วยของเดิม |
| เกิน `FB_MAX` (500) = ตัดตัวเก่าสุดทิ้ง | ค่าเดียวใน KV เพดาน 25 MB |
| ส่งได้ครั้งละไม่เกิน `FB_MAX_PER_REQ` (60) | กันยิงก้อนใหญ่ถล่ม |
| **อ่านกองต้องมีกุญแจเสมอ** · ไม่ตั้ง `FEEDBACK_KEY` = **ปิด** | ลืมตั้งแล้วข้อมูลหลุด = กู้ไม่ได้ · ค่าปริยายต้องปลอดภัย |
| ไม่มี KV = ตอบ **`ok:false` + บอกเหตุผล** ห้ามตอบว่าสำเร็จ | กับดัก "ไม่รู้ ≠ สำเร็จ" — หน้าเว็บจะขึ้นว่าส่งแล้วทั้งที่ไม่มีอะไรถูกเก็บ |
| หน้าเว็บดูที่ **`stored === true`** ไม่ใช่ `r.ok` | `ok:false` มาพร้อม status 200 ได้ |

**env ที่ต้องตั้งที่ Cloudflare** (Worker → Settings)
- `FEEDBACK_KV` — KV namespace binding · ไม่ผูก = ปุ่มส่งจะบอกตรงๆ ว่ายังเก็บไม่ได้
- `FEEDBACK_KEY` — Secret สำหรับอ่านกอง · ไม่ตั้ง = อ่านกองไม่ได้เลย (ส่งเข้าได้อยู่)

# ชั้น ③ — กฎ 6 ข้อ ที่ต้องผ่านก่อนกลายเป็นกฎจริง

| # | กฎ | เพราะอะไร |
|---|---|---|
| 1 | **ห้ามซ้ำ/ใกล้เคียงกับชุดสอบ** | เอาเฉลยมาสอนตัวเอง = คะแนนสวยแต่ปลอม · รันด้วย `leakcheck.py` (cutoff 0.70) — **เคยจับได้จริง 2 ครั้ง** |
| 2 | **ต้องคละคำตอบ ห้ามมีแต่ป้ายเดียว** | โมเดลเห็นแต่ป้ายเดียวจะตอบป้ายนั้นรัว (บทเรียนจาก `cpExamples` ของ `/admin/`) |
| 3 | **เจอ pattern เดิม ≥ 3 ครั้งถึงนับ** | แก้ใบเดียวคือรสนิยม ไม่ใช่กฎ |
| 4 | **ต้องวัดทั้งชุดออกแบบและชุดสอบไล่** | ชุดออกแบบขึ้นแต่ชุดสอบไล่ตก = ท่องจำ → **ทิ้ง** |
| 5 | **ตกแม้แต่นิดเดียว = ไม่เอา** | ไม่ใช่ "ขึ้นรวมๆ ก็พอ" |
| 6 | **มีเพดานจำนวนตัวอย่าง** | ตัวอย่างทุกอันถูกส่งไป**ทุกครั้งที่เรียก** = จ่ายเพิ่มตลอดไป (วัดจริง 29 ส.ค. 2026: 22 ตัวอย่าง = 3,257 ตัวอักษร) |
