# เทสต์ของโปรเจกต์

> ⚠️ **ตัวเว็บยังเป็น static ไม่มี build step เหมือนเดิม** — โฟลเดอร์นี้ไม่เกี่ยวกับสิ่งที่ deploy
> Cloudflare Pages ไม่แตะไฟล์ในนี้ · `package.json` ที่นี่มีไว้ให้เทสต์เท่านั้น

`CLAUDE.md` อ้างชื่อไฟล์ในโฟลเดอร์นี้อยู่หลายที่ ("เทสต์ `noise.mjs` คุมไว้")
**แก้ตรรกะที่ไหน ให้รันเทสต์ที่คุมเรื่องนั้นก่อนบอกว่าเสร็จ**

## วิธีรัน

```bash
# ครั้งแรกครั้งเดียว (เฉพาะเทสต์ที่เปิดเบราว์เซอร์จริง)
cd tests && npm install

# เทสต์ที่เปิดเบราว์เซอร์ ต้องมีเซิร์ฟเวอร์ static ที่พอร์ต 8899 ก่อน
python3 -m http.server 8899 --directory .. &

cd tests
node noise.mjs                    # ตรรกะล้วน — รันได้เลย
TZ=Asia/Bangkok node sheetorder.mjs   # ตัวที่เกี่ยวกับเวลา ต้องตั้ง TZ
```

> ⚠️ **Chromium ติดตั้งไว้ให้แล้วที่ `/opt/pw-browsers/chromium`** — เทสต์ระบุ `executablePath` เอง
> **ห้ามรัน `playwright install`** (เน็ตขาออกถูกบล็อก และไม่จำเป็น)
> · **มีแต่ Chromium — WebKit ดาวน์โหลดไม่ได้** แปลว่า **ทดสอบ Safari/iOS ที่นี่ไม่ได้**

| `syslog.mjs` | บันทึกระบบ — **ข้อสำคัญที่สุดคือห้ามกินโควตา KV** · ครอบทุก endpoint · ทุกชื่อต้องแปลไทยได้ | ✔ |
| `sharedsnip.mjs` | สรุปที่เป็นบล็อก "ข่าวที่เกี่ยวข้อง" ของเว็บ ต้องถูกตัด — **และห้ามตัดสรุปจริงทิ้ง** | |
| `install.mjs` | แถบชวนติดตั้งเป็นแอป — Chrome กดแล้วต้องเรียกกล่องจริง · iOS ต้องบอกวิธี **ห้ามมีปุ่มปลอม** · ห้ามกวนซ้ำ | ✔ |

> ⚠️ `archives.mjs` มีด่านคอยจับ **ข้อห้ามเรื่อง search library** — ถ้าวันไหนมีใครเอา
> Lunr/Fuse/MiniSearch/FlexSearch เข้ามา หรือเปลี่ยนจาก `includes()` ไปเป็นการตัดคำ
> เทสต์จะตกทันที (ลองแล้ว: เปลี่ยนเป็นเทียบทีละคำ → ตก 4 ข้อ)
> · ตัวนี้ **สร้างข้อมูลของตัวเองด้วย `page.route`** ไม่ได้อ่าน `archives/data/` ที่ commit ไว้
>   (ของที่ commit เป็นข่าวจริงจากชีต เปลี่ยนทุกครั้งที่สร้างใหม่ ถ้าเทสต์ไปผูกกับมันจะตกเอง)

> เทสต์ที่เปิดเบราว์เซอร์ **ยิงเน็ตออกนอกไม่ได้** — ทุกตัว `page.route` ปลอม API เอาเอง
> ถ้าเขียนตัวใหม่ ให้ปลอมด้วย ไม่งั้นจะไปค้างรอ Google
