# เทสต์ของโปรเจกต์

> ⚠️ **ตัวเว็บยังเป็น static ไม่มี build step เหมือนเดิม** — โฟลเดอร์นี้ไม่เกี่ยวกับสิ่งที่ deploy
> Cloudflare Pages ไม่แตะไฟล์ในนี้ · `package.json` ที่นี่มีไว้ให้เทสต์เท่านั้น

`CLAUDE.md` อ้างชื่อไฟล์ในโฟลเดอร์นี้อยู่หลายที่ ("เทสต์ `noise.mjs` คุมไว้")
**แก้ตรรกะที่ไหน ให้รันเทสต์ที่คุมเรื่องนั้นก่อนบอกว่าเสร็จ**

## วิธีรัน

```bash
# ครั้งแรกครั้งเดียว (เฉพาะเทสต์ที่เปิดเบราว์เซอร์จริง)
cd tests && npm install

# เทสต์ที่เปิดเบราว์เซอร์ ต้องมีเซิร์ฟเวอร์ static ที่พอร์ต 8899 ก่อน
python3 -m http.server 8899 --directory .. &

cd tests
node noise.mjs                    # ตรรกะล้วน — รันได้เลย
TZ=Asia/Bangkok node sheetorder.mjs   # ตัวที่เกี่ยวกับเวลา ต้องตั้ง TZ
```

> ⚠️ **Chromium ติดตั้งไว้ให้แล้วที่ `/opt/pw-browsers/chromium`**
> **ห้ามรัน `playwright install`** (เน็ตขาออกถูกบล็อก และไม่จำเป็น)
> · **มีแต่ Chromium — WebKit ดาวน์โหลดไม่ได้** แปลว่า **ทดสอบ Safari/iOS ที่นี่ไม่ได้**

## 🌐 เปิดเบราว์เซอร์ผ่าน `browser.mjs` เท่านั้น

**ห้ามเขียน `chromium.launch({ executablePath: "..." })` ในไฟล์เทสต์อีก** (แก้ยกชุด 25 ส.ค. 2026)
ของเดิม 16 ไฟล์ผูกกับที่อยู่ไฟล์ในเครื่องนี้ตายตัว → ย้ายไปรันที่อื่นไม่ได้ และเปลี่ยนเอนจินไม่ได้

```js
import { launch } from "./browser.mjs";
const browser = await launch();
```

`browser.mjs` จะใส่ `executablePath` ให้เฉพาะตอนที่ไฟล์มีจริง (ในเครื่องนี้)
ที่อื่นปล่อยให้ Playwright หาเอง · เลือกเอนจินด้วย env **`TEST_BROWSER=webkit`**

### 🍎 ฝั่ง Safari/iOS รันที่ GitHub Actions

`.github/workflows/tests.yml` รันชุดนี้ทั้ง **chromium** และ **webkit** ทุกครั้งที่ push

> ⚠️ **WebKit ที่นั่นไม่ใช่ Safari บน iPhone** — เครื่องยนต์เดียวกันจึงจับเรื่อง CSS/JS ที่
> Safari ไม่รองรับได้ แต่**ไม่มี**เมนูแชร์ · ไม่มีการเพิ่มลงหน้าจอโฮม · ไม่มี `navigator.standalone`
> **ผ่านที่นั่นไม่ได้แปลว่าทดสอบ Safari แล้ว** — เรื่องพวกนั้นต้องเปิด `/selftest/` บนเครื่องจริง
>
> ⚠️ ฝั่ง WebKit ตั้ง `continue-on-error` ไว้ก่อน เพราะ**ยังไม่เคยมีใครรันชุดนี้บน WebKit เลย**
> (เครื่องที่เขียนเทสต์โหลด WebKit ไม่ได้) รอบแรกๆ อาจตกเพราะเทสต์ผูกกับ Chromium ไม่ใช่เพราะเว็บพัง
> **ไล่แก้ครบเมื่อไหร่ให้ลบบรรทัดนั้นทิ้ง** ไม่งั้นมีไว้ก็ไม่ได้กันอะไร
